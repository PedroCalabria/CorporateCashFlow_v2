# Corporate Treasury & Cash Flow Management System

A single-company, multi-subsidiary corporate treasury and cash-flow management
system (portfolio project). This repository is a **monorepo** containing the
.NET backend, the React frontend, the local Docker Compose environment, and the
project's specifications.

> **Status:** `project-bootstrap` — this is the initial scaffolding only. There
> is no business logic yet: no entities, endpoints, screens, or rules. The goal
> is a skeleton that builds and boots locally. Business capabilities
> (`app-shell`, `auth`, …) are added by subsequent OpenSpec changes.

## Repository layout


## Prerequisites

- [Docker Desktop](https://www.docker.com/products/docker-desktop/) (Docker
  Engine 24+ and Docker Compose v2).

That is the only requirement to run the stack. The .NET SDK and Node.js are only
needed if you want to build or run the projects **outside** of Docker.

## Running the environment

From the repository root:

```bash
docker-compose up --build
```

This builds and starts three services:

| Service    | URL                              | Purpose                                  |
| ---------- | -------------------------------- | ---------------------------------------- |
| `frontend` | http://localhost:5173            | React app (example page)                 |
| `api`      | http://localhost:8080            | .NET API                                 |
| `db`       | localhost:5432                   | PostgreSQL                               |

Useful endpoints on the API:

- `http://localhost:8080/health` — health probe (returns `{ "status": "ok" }`)
- `http://localhost:8080/hangfire` — Hangfire dashboard (open in this change; a
  Manager-only authorization filter is added once auth exists)

Report files generated by future capabilities are persisted to the
`reports-data` named volume, mounted into the `api` container at `/app/reports`.

To stop the stack:

```bash
docker-compose down          # stop and remove containers
docker-compose down -v       # also remove the named volumes (db data + reports)
```

### Configuration

Defaults are baked into `docker-compose.yml`. To override the database
credentials, copy `.env.example` to `.env` and edit it:

```bash
cp .env.example .env
```

## Working outside Docker (optional)

Backend:

```bash
cd backend
dotnet build          # builds all six projects
dotnet run --project src/CorporateTreasury.Api
```

(Requires a PostgreSQL reachable at the connection string in
`backend/src/CorporateTreasury.Api/appsettings.json`.)

Frontend:

```bash
cd frontend
npm install
npm run dev           # http://localhost:5173
npm run build         # production build
```
